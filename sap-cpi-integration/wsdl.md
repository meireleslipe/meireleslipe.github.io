# Consumindo Web Service

Estudo prático de integração de Web Services no SAP Cloud Integration,
abrangendo consumo SOAP, WSDL, autenticação e exposição de integração
via HTTPS.

---

## Temas abordados

- Web Services
- SOAP
- WSDL
- SOAP UI
- SAP Cloud Integration
- iFlow
- Request Reply
- Client ID e Client Secret
- Autenticação
- Integração SOAP 2 SOAP
- Conversão de JSON para SOAP
- Recebimento de JSON via HTTPS
- Deploy e monitoramento de integrações

---

## Projetos desenvolvidos

### EX002 Calculadora Add

Integração SOAP 2 SOAP utilizando SAP Cloud Integration.

### EX002 Calculadora Add With WSDL

Integração SOAP utilizando definição WSDL.

### EX002 Calculadora Add Receiving Json

Integração recebendo JSON via HTTPS e realizando o processamento
para consumo do serviço SOAP.
