## Projetos desenvolvidos

### API REST Calculator

API REST desenvolvida no SAP Cloud Integration para receber uma operação matemática e dois valores, direcionando a requisição para o processamento correspondente.

O projeto contempla as operações de **adição, subtração, multiplicação e divisão**, utilizando integração com Web Service SOAP.

Também foram utilizados **Local Integration Process**, **Process Call** e **ProcessDirect** para modularização do processamento e comunicação entre iFlows.
