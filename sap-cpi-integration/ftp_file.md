## Projetos desenvolvidos

### FTP FILE Create

iFlow desenvolvido para receber dados via SOAP e salvar o conteúdo em um arquivo XML em um servidor FTP.

### FTP FILE Read

iFlow desenvolvido para ler arquivos XML de um diretório FTP e enviar seu conteúdo por e-mail utilizando SMTP.
